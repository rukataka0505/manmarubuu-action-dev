# Gemini Web（Taskモード）用：まんまるぶう 新マップ上流設計プロンプト

```markdown
以下の公開リポジトリの仕様書（`GAME_SPEC.md`）と実コード（`game-web/src/`）を読み込み、ワールド1を超える面白さの **「ワールド2（新マップ）」の上流設計〜検証まで** を自律的に進めてください。

対象リポジトリ: https://github.com/rukataka0505/manmarubuu-action-dev

### やってほしいこと（進め方・アイデアはおまかせ）
1. **新マップの企画＆レベルデザイン**: 世界観（陽だまりのクラフト・おもちゃ箱 × 手縫いぬいぐるみ）に合う最高の新ワールドを考案し、導線・ギミック・敵・ボス戦まで設計する。
2. **実コード準拠の数値検証＆図面**: `ManmarubuuController.ts` や `World1Builder.ts` 等の実際の物理定数・APIに合わせて、到達性の検証や見取り図を作成する（存在しないクラスや数値の捏造はNG）。
3. **3Dプレビュー／簡易QA（ベストエフォート）**: 環境でできる範囲で、3D白箱ビューア（単一HTML）や型チェック・簡易動作確認まで挑戦してみる。環境制約で無理な部分は深追いせず、何で止まったかだけ教えてほしい。
4. **ローカル実装（Agy）へそのまま渡せる出力**: 設計書・レイアウト定義コード（TypeScript）・引き継ぎ指示書を用意する。

### 出力・保存先
- 生成した設計書・コード・HTMLビューア・図面は **Google ドライブ（または Google ドキュメント）に分かりやすく整理して保存**し、チャットには「全体の要約・保存先リンク・やってみて分かった制約や提案」を簡潔に報告してください。
```
