# **1\. 達成目標（Goal）**

公開リポジトリの `game-web` モジュールに対し、ワールド1の操作性および 60fps 安定性を維持したまま、立体移動と物理連鎖を進化させた World 2「スイーツ工場のふわふわ雲（SUGAR CLOUD BAKERY）」 を統合実装し、一気通貫でプレイ可能な状態を確立する。

# **3\. 機能要件**

## **Phase A: MVP（基盤統合・完全プレイアブル化）**

* **マルチワールド構造とセーブデータの拡張**  
  * ワールドセレクト画面にて World 1 と World 2（`worldId: 'world2'`, `catalogId: 2`）の選択・切替を可能とすること。  
  * スター収集状態・チェックポイント到達状態・クリアランク・ハイスコアがワールドごとに独立して保存される構造を実装すること。  
* **ワールド2 コース構造・全6エリアの実装**  
  * 検証済みレイアウト定義に準拠し、全6エリア（スポーン地点、3段ケーキハブ、東マシュマロバウンス湾＆3連バネタワー＆キャラメル帰還スライダー、西ストロベリー・キャンディスライダー＆北西クッキー・ボーリング広場、北ボスアリーナ）を構築すること。  
  * メンスター3個および隠しスター3個（計6個）を配置し、すべて到達・獲得可能とすること。  
  * スポーン初期座標 `(0, 1.2, 46)` および落下時の復帰処理が正常に機能すること。  
* **ゲート・架橋・ゴールの座標統合**  
  * ワールド2固有の各要所座標を正確に制御すること。  
    * 3スター解放ゲート: `(0, 1.5, -12.5)`  
    * 虹の橋渡航ルート: `(0, 1.5, -12.5)` \$\\rightarrow\$ `(0, 5.0, -35.5)`  
    * ボスアリーナ座標: `(0, 5.0, -54)`  
* **ボス戦（PATISSERIE CLOCKWORK CHEF）の実装**  
  * 3フェーズ構造、背部ぜんまい弱点判定、外周マシュマロ床ギミックを実装すること。  
  * Phase 2 以降のスライム召喚（またはワールド2演出）を動作させ、撃破後に宝箱ゴールおよびクリアリザルト画面へ遷移させること。

## **Phase B: 拡張要件（固有ギミック・ルック強化）**

* **追加ギミック実装**  
  * 回転クッキー歯車足場（`WORLD2_PHASE_B_GEARS`）およびベルトコンベア通路（`WORLD2_PHASE_B_CONVEYORS`）の動的物理処理。  
  * ヒップドロップに連動するスーパーマシュマロ跳躍アクション。  
* **ビジュアル・アセットの強化**  
  * スイーツ工場をイメージしたパステル空・照明パラメーターの適用。  
  * ワールド2専用Blender / GLBモデルへのアセット置換。  
* **実装自由度**  
  * アーキテクチャ詳細、内部ファイル分割、リファクタリング手法、アセット構築手順等の決定権限はすべて Agy 側に一任する。

# **4\. 制約条件**

## **物理定数・API整合性**

* `ManmarubuuController.ts` に定義された移動物理定数を変更・破損しないこと。  
  * 通常移動速度: `10.6 m/s`  
  * 滑り台移動速度: `18.5 m/s`  
  * 1段ジャンプ初速: `12.6` / 2段ジャンプ初速: `11.4` / クッション跳躍初速: `14.0`  
  * 落下リスポーン判定閾値: `Y < -14.0`  
* `PhysicsWorld.ts` に定義された物理制約を遵守すること。  
  * 最大登坂角度: `52°`  
  * 動的剛体上限数: `160`

## **独立性とデータ互換性**

* 既存の World 1 セーブデータ（`manmarubuu_save_v2`）に対する後方互換性を完全に維持すること。  
* 全チェックポイントの配置座標は `|x| <= 85`, `|z| <= 85`, `-5 <= y <= 40` の境界範囲内に収めること。

## **パフォーマンスおよび描画表現**

* PCブラウザ環境において常時 60fps を安定維持すること。  
* モバイル低品質モード（`low`）実行時は、距離カリングおよびインスタンスドロー（Instanced Mesh）による軽量化方針を維持すること。  
* 世界観「陽だまりのクラフト・おもちゃ箱 × 手縫いぬいぐるみ」の質感表現（ブラウン刺繍の表情、フェルト、木製、パステル調おもちゃの質感）をトーン＆マナーとして厳守すること。

# **5\. 受け入れ基準（Acceptance Criteria）**

1. **ビルド検証**  
   `npm run typecheck`（`tsc --noEmit`）および `npm run build`（Vite本番ビルド）を実行した際、型エラーおよびビルドエラーが0件であること。  
2. **回帰検証**  
   World 1 のゲームプレイ、クリアフロー、および既存セーブデータのロード処理に一切の退行（リグレッション）が発生しないこと。  
3. **通しプレイ検証**  
   World 2 において、デバッグ用テレポート等を使用せず、通常操作のみでメインスター3個および隠しスター3個（計6個）が回収可能であること。また、3スター解放後の「虹の橋渡航 \$\\rightarrow\$ ボス撃破 \$\\rightarrow\$ 宝箱開封 \$\\rightarrow\$ クリアリザルト表示」のフローが一気通貫で正常完了すること。  
4. **例外・復帰動作検証**  
   すべてのチェックポイント復帰、落下リスポーン、およびゲームオーバー後のリトライ処理において、プレイヤーキャラクターのスタックやスタック座標への復帰が発生しないこと。  
5. **実機描画検証**  
   実機ブラウザ環境（または自動検証スクリプト）において全エリアの視覚検品を行い、オブジェクトの床抜け、めり込み、および極端なフレームレート低下が発生しないことを確認すること。
